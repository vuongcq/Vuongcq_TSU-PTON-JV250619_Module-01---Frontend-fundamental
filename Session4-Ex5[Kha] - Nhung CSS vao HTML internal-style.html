What is CSS?

With CSS, youcan control the color, font, the size of tex, the spacing between elements, how elements are

positioned and laid out, what background images of background colors are tobe used, different displays for

different devices and screen sizes, and much more!

Tip: The word cascading means that a style applied to a parent element well also apply to all children

elements within the parent. So, if you set the color of the body text to "blue", all headings, paragraphs, and

other text elements within the body will also ger the same color (unless you specify something else)
